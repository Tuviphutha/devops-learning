# Linux Basic

## 📌 Mục tiêu

Bài học này tập trung vào việc xây dựng kiến thức nền tảng và làm chủ hệ điều hành Linux, sử dụng môi trường thực hành:

```text
Ubuntu Server 24.04
```

Sau khi hoàn thành phần Linux Basic, mục tiêu là có thể:

- Sử dụng Terminal một cách thành thạo.
- Hiểu cấu trúc Linux Filesystem.
- Di chuyển và quản lý File/Directory.
- Quản lý User và Permission.
- Kiểm tra và quản lý Process.
- Cài đặt và quản lý Package.
- Quản lý Service bằng systemd.
- Kiểm tra Network cơ bản.
- Đọc và phân tích System Logs.
- Thực hiện các thao tác quản trị Linux Server cơ bản.

## 03. Linux Filesystem

```text

├── var

├── usr
└── opt
```


## 04. Directory Navigation

Các câu lệnh:

```bash
pwd
ls
cd
tree
```


## 05. File Management

Các thao tác:

```bash
touch
mkdir
cp
mv
rm
rmdir
```


## 06. Text Processing

Các câu lệnh:

```bash
cat
less

tail
grep

```


## 07. Users & Permissions

Các nội dung:

```text
User
Group
sudo
chmod
chown
```


## 08. Process Management

Các câu lệnh:

```bash
ps
top
htop
kill
```


## 09. Package Management

Ubuntu sử dụng:

```bash
apt
```

Ví dụ:

```bash
sudo apt update
sudo apt install nginx
```


## 10. Service Management

Quản lý Service bằng:

```bash
systemctl
```

Ví dụ:

```bash
systemctl status nginx
systemctl start nginx
systemctl stop nginx
```


## 11. Network Basic

Các nội dung:

```bash

```


## 12. System Logs

Các nội dung:

```bash

```
